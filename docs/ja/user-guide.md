# ユーザーマニュアル

一般の利用者（ページの閲覧者・編集者）向けに、地図の表示操作と、GUI での地図の作成・編集手順を説明します。記法の細かい仕様は {doc}`syntax-reference` を参照してください。

## 地図を表示する（閲覧）

`:::custom-map` 記法が書かれたページを開くと、起動ボタン（既定のテキストは「マップを開く」）が表示されます。ボタンを押すと平面図がモーダルで開きます。

### 表示モーダルの操作

```{list-table}
:header-rows: 1
:widths: 40 60

* - 操作
  - 動作
* - 起動ボタンをクリック
  - 平面図をモーダルで表示
* - ドラッグ / 1 本指スワイプ
  - 表示位置を移動（パン）
* - ホイール / 2 本指ピンチ
  - カーソル（中点）を中心に拡大 / 縮小（ズーム）
* - マーカー / ラベルを左クリック・タップ
  - そのマーカーとラベルを最小化 / 再表示（トグル）
* - マーカー / ラベルを右クリック・ロングタップ
  - 参照写真・説明文をポップアップ表示
* - 背景クリック / × ボタン
  - 閉じる
```

### マーカーの最小化と自動復帰

マーカーやラベルを左クリック・タップすると **最小化** され、ラベルが隠れてピンだけが点滅します。ラベルで隠れていた平面図の部分を確認したいときに使います。最小化中のピンは、記法の `pinSize` とは無関係の固定サイズ（既定 24px）で、位置が分かりやすいようやや大きめに表示されます。

`restore` で指定した秒数（既定 15 秒）が経過すると、最小化したマーカーは **自動的に元へ戻ります**。

### 説明文つきマーカーの目印

説明文・注意書き（`desc`）が設定されたマーカーは、**ピンが点滅** して存在を知らせます。右クリック・ロングタップでポップアップを開くと、参照写真と説明文を確認できます。

## 地図を作成する（GUI）

記法を手書きせずに、編集画面の GUI で地図を作れます。

1. ページを **編集モード** で開き、**記法を挿入したい位置にカーソルを置きます**。記法は、ボタンをクリックした **直前のカーソル位置** に挿入されます。
2. 画面右下の **「🛠️ 地図を作成」** ボタンをクリックします。
3. 平面図を選びます（選ぶと記法の `file` が自動で入ります）。
   - **変換 API あり**: 登録済みの地図アセット一覧（MAP 編集者が登録した CAD・画像）から選びます（登録名・元ファイル名で絞り込み可）。`file` には登録名が入ります。
   - **変換 API なし（お手軽運用）**: ストック用ページ（既定 `/media-library`）の添付画像一覧から選びます。`file` には添付ファイル名が入ります。
4. 平面図の上を **クリックしてマーカーを配置** します（ホイール / ピンチで拡大して細かい位置も指定できます）。
5. 右のパネルで、選択中マーカーの **ラベル・参照写真・色・説明文** を入力します（座標 X/Y の微調整も可能）。不要なマーカーは削除できます。
6. 必要なら **地図全体の設定**（起動ボタンの文言、自動復帰秒、初期表示の中心・倍率、回転）を調整します。回転は `0° / 90° / 180° / 270°` のボタンで切り替えると、プレビューにすぐ反映されます。
7. **「確定して挿入」** で、`:::custom-map` 記法がカーソル位置に挿入されます。

```{important}
記法は「🛠️ 地図を作成」ボタンをクリックした **直前のカーソル位置** に挿入されます。意図した場所に入るよう、ボタンを押す前にカーソル位置を確認してください（挿入したい行・段落にカーソルを置いてからボタンをクリックします）。カーソルが既存の `:::custom-map` の中にあるときは、誤挿入を防ぐため新規挿入されず、「地図を編集」を促すメッセージが表示されます。
```

```{note}
**変換 API あり** の場合、GUI の平面図一覧は API に登録済みの地図アセット（`GET /assets`）から取得します。ストック用ページ（`/media-library`）を編集グループのみ閲覧可に絞る秘匿運用でも、一般編集者が地図を選べるようにするためです。一覧に無い図面を使いたい場合は、MAP 編集者に「地図アセットの登録」からの登録を依頼してください。

**変換 API なし** の場合は、ストック用ページ（既定 `/media-library`）の添付画像一覧をそのまま表示します。この運用では一覧の画像がストックページの閲覧権限に従うため、ストックページを閲覧できる状態（＝秘匿しない）にしておく必要があります。
```

### マーカーのドラッグ移動

配置済みのマーカーは、ドラッグして位置を変更できます。5px 以上動かすとドラッグ扱いになり、回転・拡大・パン中でも元画像基準の座標へ正しく換算されます。しきい値未満のクリックは従来どおり「選択」として扱われます。選択中マーカーをドラッグすると、右パネルの X / Y 入力欄にも即座に反映されます。

## 既存の地図を編集する（GUI）

ページに挿入済みの地図を、GUI で編集し直せます。

1. ページを **編集モード** で開きます。
2. 画面右下の **「🖊️ 地図を編集」** ボタンをクリックします。
3. このページ内の地図一覧（`:::custom-map` ブロック）から、編集したい地図を選びます。
4. マーカーの追加・移動・削除、ラベル・色・説明文・回転・初期表示などを GUI で編集します。
5. **「変更を保存」** で、元の記法が **同じ場所に上書き保存** されます（保存後にページが再読み込みされます）。

```{important}
「地図を編集」は **保存済みのページ本文** を対象にします。編集中に未保存の変更がある場合は、先にページを保存してから「地図を編集」を使ってください（未保存分が失われるのを防ぐため）。
```

```{note}
一覧には、登録アセット（登録名）を参照している地図のみが編集対象として表示されます。古い方式（media-library の生ファイル名を直接参照）の地図は「登録アセットではありません」と表示され編集できません。その場合は「地図を作成」で新方式に作り直してください。
```

## マーカーに写真と説明を付ける

各マーカーには、参照写真（`photo`）と説明文（`desc`）を付けられます。

- **参照写真**: 右クリック・ロングタップのポップアップに画像を表示します。ファイル名で指定し、記法を書いたページの添付や、`photoSrc` で指定したページから解決されます。
- **説明文**: `|`（パイプ）で改行できます。予約の要否・内線番号・注意事項など、短い補足を載せる用途に向きます。説明文を設定したマーカーはピンが点滅します。

写真のアップロードや切り抜き（トリミング）も編集 GUI から行えます。写真欄の「⬆ 画像をアップロード」で、選択した画像を現在ページの添付として登録し、`photo` に自動反映できます。アップロード前に切り抜きモーダルで範囲を指定することもできます。

## よくある操作の質問

- **どこに地図が挿入される？** 「地図を作成」ボタンを押す直前のカーソル位置です。
- **地図が表示されない**: {doc}`admin-guide` の「トラブルシューティング」を参照してください。多くは `file` の名前ずれか、ストックページの閲覧権限が原因です。
- **図面の向きを直したい**: 記法の `rotate` で表示時に回せます。CAD を恒久的に正しい向きで登録したい場合は、MAP 編集者が「地図アセットの登録」で向きを焼き込んで別名登録します（{doc}`admin-guide` 参照）。
