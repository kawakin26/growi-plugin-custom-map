# 記法リファレンス

`:::custom-map` 記法の全属性を説明します。GUI で作成した記法も、この仕様に沿った Markdown として挿入されるため、手で微調整できます。

## 基本構造

記法は Markdown の [ディレクティブ記法](https://github.com/remarkjs/remark-directive)（`remark-directive`）を使います。コンテナの属性が **平面図全体の設定**、本文の箇条書き 1 行が **1 つのマーカー** に対応します。

````md
:::custom-map{file="1F平面図.png" cx="50" cy="40" scale="2" rotate="90" link="1階の案内図を開く" restore="15"}
- x=30 y=40 label="受付" photo="reception.jpg" color="#ff3b30"
- x=70 y=55 label="会議室A" photo="room_a.jpg" desc="予約制|内線 101"
- x=20 y=80 label="非常口" photo="exit.jpg" color="#34c759" desc="施錠注意|夜間は警備室へ連絡"
:::
````

```{tip}
値にスペースを含む場合はダブルクォート（`"..."`）で囲ってください（例: `label="第1会議室"`）。
```

## 平面図全体の設定（コンテナ属性）

```{list-table}
:header-rows: 1
:widths: 14 66 20

* - 属性
  - 説明
  - 省略時
* - `file`
  - 平面図の **登録アセット名**（必須・推奨。GUI で選ぶと自動で入る）。後方互換として添付のオリジナルファイル名（`.png` / `.dxf` / `.jww` 等）も指定可だが、秘匿運用では解決できないことがある
  - —
* - `src`
  - 平面図画像を探す参照ページのパス
  - 規定ページ
* - `cx`
  - 初期表示の中心 X 座標（画像に対する %、0〜100）
  - `50`
* - `cy`
  - 初期表示の中心 Y 座標（画像に対する %、0〜100）
  - `50`
* - `scale`
  - 初期倍率。画像が表示窓に収まる倍率に対する係数
  - `1`
* - `rotate`
  - 平面図全体の回転角（`0` / `90` / `180` / `270` のいずれか。時計回り、度）。向きずれの補正に使う
  - `0`
* - `link`
  - 平面図を開く起動ボタンのテキスト
  - `マップを開く`
* - `restore`
  - 最小化したマーカーが自動で復帰するまでの時間（秒）
  - `15`
* - `pinSize`
  - マーカーのピン径（px、マップ全体共通）。`6`〜`48` にクランプ
  - `12`
* - `labelSize`
  - マーカーのラベル文字サイズ（px、マップ全体共通）。`8`〜`40` にクランプ
  - `12`
```

### 座標系について

`cx` / `cy` と各マーカーの `x` / `y` は、いずれも **元画像に対する百分率（0〜100）** です。画像の左上が `(0, 0)`、右下が `(100, 100)` に相当します。回転（`rotate`）を掛けても、座標は常に **回転前の元画像基準** で解釈されるため、向きを変えてもマーカー位置がずれません。

### 回転の合算

`rotate` は表示時に CSS で回します。CAD 登録アセット（後述）で向きを焼き込んでいる場合、記法の `rotate` は **その上にさらに上乗せ** されます。恒久的な基準の向きは登録時に焼き込み、ページごとの一時的な向きは記法の `rotate` で調整する、という使い分けができます。

## 各マーカーの設定（箇条書き）

```{list-table}
:header-rows: 1
:widths: 14 66 20

* - キー
  - 説明
  - 省略時
* - `x`
  - マーカーの横位置（画像に対する %、0〜100、**必須**）
  - `50`
* - `y`
  - マーカーの縦位置（画像に対する %、0〜100、**必須**）
  - `50`
* - `label`
  - マーカーに表示するラベルテキスト
  - なし
* - `photo`
  - 右クリック / ロングタップで表示する参照写真のオリジナルファイル名
  - なし
* - `photoSrc`
  - 参照写真を探すページのパス
  - 記法を書いたページ → 地図の解決先
* - `desc`
  - 説明文 / 注意書き（`\|` で改行）。設定するとピンが **点滅** し、右クリック / ロングタップのポップアップに表示される
  - なし
* - `color`
  - ピンとラベルの色（CSS カラー）
  - `#ff3b30`
```

### 複数写真と写真ごとの説明（子リスト方式）

1 つのマーカーに複数の参考写真を持たせ、写真ごとに説明を付けることもできます。マーカー行の下に、2 スペースのインデントで子リストを書きます。

````md
- x=30 y=40 label="受付" desc="内線 101"
  - photo="reception_1.jpg" desc="正面から"
  - photo="reception_2.jpg" desc="受付台のアップ"
````

- 子リストの各行が写真 1 枚に対応します（番号に依存せず、行単位で追加・削除・並び替えができます）。
- 写真行の `desc` は、その写真へのコメントです（マーカー行の `desc` とは階層で区別されます）。

## 画像の解決順

記法で指定した名前がどのように実ファイルへ解決されるかを示します。詳しい運用は {doc}`admin-guide` を参照してください。

- **平面図（`file`）**:
  1. **登録アセット**（CAD の焼き込み SVG / 画像原本）を **API 配信 URL** で最優先に解決（`file` が登録名のとき。CAD・画像とも。ストック秘匿でも表示でき、閲覧者権限に依存しない）
  2. 未登録の CAD は変換 API で **都度変換**
  3. 未登録は従来の添付解決（`src` 指定ページ → 規定ストックページ `/media-library`）→ 静的パス
- **参照写真（`photo`）**: `photoSrc` 指定ページ → 記法を書いたページ自身 → 平面図と同じ解決先（添付解決）

添付解決は、該当ページの添付一覧から `originalName` / `fileName` を照合して URL を解決します。見つからない場合は `/images/maps/{ファイル名}` にフォールバックします。

```{important}
添付ファイルの閲覧権限は **添付元ページ** に従います（変換 API を使わない場合）。ストック用ページの閲覧権限が無いユーザーには画像が表示されません。共有したい相手全員が閲覧できる公開範囲でストック用ページを作成してください。登録アセット（変換 API あり）の場合はこの制約を受けません。
```
