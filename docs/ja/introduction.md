# はじめに

## このプラグインの目的

`growi-plugin-custom-map` は、GROWI のウィキ文書内に **平面図（フロアマップ）とマーカー** を埋め込むためのプラグインです。平面図の上に Google マップのピンのようなマーカーを置き、各マーカーにラベル・参照写真・説明文を紐付けられます。建物の案内図、設備の配置図、避難経路図など、「図の上の特定の位置に情報を載せたい」用途を想定しています。

平面図は、アップロード時の **オリジナルのファイル名** で参照します。GROWI の添付ファイルはランダムな ID で管理されますが、このプラグインを使うと `file="1F平面図.png"` のように人間が読める名前で指定できます。

## できること（概要）

- **平面図の表示**: 記法で指定した平面図をモーダルで開き、ドラッグ・ホイール/パン・ピンチで移動と拡大縮小ができます。
- **マーカーの配置**: 1 枚の平面図に複数のマーカーを置き、位置・ラベル・色・参照写真・説明文を指定できます。
- **GUI での作成・編集**: 記法を手書きしなくても、編集画面のフローティングボタンから平面図をクリックしてマーカーを配置し、記法を自動生成できます。既存の地図を選んで編集し直すこともできます。
- **回転**: 平面図全体を 90° 単位で回転して表示できます（撮影・スキャンの向きずれの補正）。
- **CAD 図面（任意）**: 別途の変換 API を設定すると、DXF / JWW の CAD 図面を SVG に変換して表示できます。向きを確定した図面を別名で登録することもできます。

## 全体像（コンポーネント）

このプラグインは、機能ごとに独立したモジュールで構成されています。

```{list-table}
:header-rows: 1
:widths: 20 80

* - モジュール
  - 役割
* - `viewer`
  - 記法 `:::custom-map` を解釈し、地図モーダルとして表示する。閲覧時に動作する中心機能。
* - `editor`
  - 編集画面にフローティングボタンを出し、GUI での地図の新規作成・既存編集を担う。
* - `register`
  - ストックページで CAD・画像を「登録アセット」として別名登録する UI。変換 API 設定時のみ有効。
* - `common`
  - 上記が共有するユーティリティ（添付解決、設定読み取り、ラベル文字色判定など）。
```

各機能はエントリポイントで **独立した try-catch により起動** されるため、編集や登録の機能が GROWI のアップデートで壊れても、表示機能は動き続けます。

## 動作の二段構え：変換 API の有無

このプラグインは、**CAD 変換 API を使うかどうか** で運用が二段構えになります。ドキュメント全体でこの区別が繰り返し登場します。

```{list-table}
:header-rows: 1
:widths: 22 39 39

* -
  - 変換 API あり
  - 変換 API なし（お手軽運用）
* - 画像の保存先
  - API サーバーのストレージ（登録時に取り込み）
  - GROWI のページ添付
* - 参照経路
  - API 配信（GROWI 権限とは独立）
  - GROWI 標準の `/attachment/{id}`（閲覧権限に従う）
* - ストックページの秘匿
  - 可能（編集グループのみ閲覧可でも地図は表示される）
  - 不可（画像を置いたページを公開しておく必要がある）
* - CAD 図面
  - 表示・向き登録が可能
  - 使わない（画像のみ）
```

- **お手軽に使いたい**、CAD を扱わない場合は、変換 API なしで始められます。ストックページ（既定 `/media-library`）に画像を添付し、記法から名前で参照するだけです。
- **CAD を扱いたい**、または **ストックページを秘匿したまま地図だけ見せたい** 場合は、変換 API（[growi-cad-convert-api](https://github.com/kawakin26/growi-cad-convert-api)）を導入します。

詳しい設定は {doc}`admin-guide` を参照してください。
